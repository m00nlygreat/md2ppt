# LOG

프로젝트 관련 중대 결정사항, 새로 알아낸 사실, 방향 변경을 시간순으로 기록한다.

## 2026-06-03

- 내장 PowerPoint 템플릿은 루트 파일이 아니라 Python 패키지 데이터로 관리한다.
- 내장 템플릿은 `--template`과 `--list-templates`로 이름 기반 접근을 제공하고, `--ref`는 사용자 제공 PPTX 경로에만 사용한다.
- layout이 명시된 빈 슬라이드는 삭제하지 않고 해당 layout을 적용하기로 했다.
- layout 자동 판정은 빈 슬라이드 제거 이후 남은 슬라이드에만 적용한다.
- 프로젝트 위키 문서로 [요구사항](REQUIREMENT.md)과 [변경 로그](LOG.md)를 유지한다.
- [요구사항](REQUIREMENT.md)은 제품 설명보다 기능 요구사항에 한정해 유지한다.
- [요구사항](REQUIREMENT.md)에 Template/Ref PPT 메타정보 요구사항을 추가했다.
- 도형 이름 JSON 메타정보의 `id`, `show_anyway`로 named shape 텍스트 입력과 조건부 제거를 지원한다.
- 제목 슬라이드 named shape는 YAML frontmatter 값을 사용하고, 같은 `id` 도형 여러 개에 동일 입력을 적용한다.
- `--no-toc` 옵션으로 TOC 슬라이드 생성을 건너뛸 수 있게 한다.

## 2026-10-21

- 기존 PPTX 출력에 더해 같은 Markdown으로 로컬 웹서버를 실행해 발표하는 모드를 추가하기로 했다.
- embed flatten과 슬라이드 구분·레이아웃 규칙을 재사용하고, 16:9 화면을 별도 HTML/CSS 웹 테마로 그린다.
- PPTX 템플릿의 좌표·글꼴·도형을 그대로 재현하는 방식은 채택하지 않는다.
- 초기 계획에서 자동 감지와 발표자 화면은 후속 범위로 두었다.
- 공통 slide JSON 파이프라인을 추출하고 `serve` CLI, 안전한 HTML 렌더러, 등록 이미지 전용 HTTP 서버를 구현했다. 내장 웹 리소스의 wheel 포함과 기존 PPTX CLI 호환을 검증했다.

## 2026-10-22

- [PLAN.md](../PLAN.md)를 외부 CSS 테마 지원 계획으로 전면 교체했다. 기능 구현은 다음 작업으로 둔다.
- 슬라이드 레이아웃과 각 화면 요소의 스타일을 외부 CSS로 정의하고, 기본 테마를 프로젝트 루트의 [styles/default.css](../styles/default.css)에 저장하기로 했다.
- `serve --theme <CSS 경로>`로 사용자 CSS를 선택하고, 옵션 생략 시 기본 테마를 사용하도록 계획했다.
- [요구사항](REQUIREMENT.md)에 웹 CSS 테마 요구사항과 구현 예정 상태를 추가했다.
- 기본 발표 CSS를 [styles/default.css](../styles/default.css)로 통합하고, `--theme` 경로 검증·요청 시 CSS 재로딩·패키지 리소스 제공을 구현했다.
- 테마는 화면 구조를 꾸미는 완성형 CSS로 정했다. 레이아웃, placeholder 열 수, 표 정렬은 렌더러의 클래스와 `data-*` 속성으로 전달한다.
- wheel과 소스 배포본에 기본 CSS가 포함되는 것을 확인했다. 별도 설치 위치에서 기본·사용자 테마를 실행하고, 브라우저에서 크기 계산·이동·전체 화면·넘침 안내와 사용자 CSS의 색상·열 비율 변경을 확인했다.
- [PLAN.md](../PLAN.md)를 Reveal.js 웹 프레젠터 전환 계획으로 교체했다. 당시 구현 예정으로 두었으며, Markdown 해석과 HTML 생성은 md2ppt에 두고 발표 기능을 Reveal.js에 맡긴다.
- 기준 버전은 공식 배포본 6.0.2로 고정하고, JS·CSS·Notes 플러그인·MIT LICENSE를 Python 패키지에 포함하기로 했다.
- 발표자 화면과 기존 노트 연결을 이번 전환 범위에 포함했다. CSS 이전, 기존 URL 호환, 콘텐츠 맞춤과 패키지 설치 검증도 계획에 반영했다.
- Notes 플러그인은 팝업에 인라인 스크립트를 작성하고 iframe으로 발표를 미리 본다. 현재 CSP와 충돌하므로 같은 origin 미리보기와 고정 스크립트 hash만 허용하도록 계획했다.
- [PLAN.md](../PLAN.md)의 Reveal.js 전환을 구현 완료했다. 6.0.2 배포 리소스와 해시·라이선스를 패키지에 포함하고, 전용 URL 허용 목록과 Notes CSP를 구성했다.
- 브라우저에서 실제 91장 강의 자료와 별도 노트 샘플을 확인했다. 발표자 노트 안전 렌더링, 슬라이드 이동 동기화와 새로고침 복구가 동작했다.
- wheel·sdist 및 sdist에서 재빌드한 wheel을 저장소 밖에서 확인했고, 전체 테스트 12개가 통과했다.
